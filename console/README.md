# console/

The Next.js admin console (Lane D task 4) will be a pure client of the admin API (A1). Today
this directory holds only the TypeScript client generated from
[`controlplane/openapi/admin-api.json`](../controlplane/openapi/admin-api.json):

| Path | What |
|---|---|
| `src/client/` | Generated by `@hey-api/openapi-ts` (fetch client, types, one SDK function per operation). Never edited by hand. |
| `openapi-ts.config.ts` | Generator configuration. |
| `scripts/run.sh` | Steps run in the pinned Node container by `make console-client` and `make console-client-check`. |

CI's `a1-drift` job fails if FastAPI's output differs from the committed document, or if the
committed client differs from a fresh generation. A1's other half, that the console calls no
endpoint missing from the contract, arrives with the console UI, which will call the API only
through this client. The document moves under `contracts/` in a later spec-change PR.
